## 1. Общий алгоритм интегрирования рациональных дробей

> 💡 **Смысл / Заметка лектора:** Интегрирование применяется только на последнем, пятом шаге алгоритма. Первые четыре действия — это сугубо алгебраическая работа с самой дробью (приведение к общему знаменателю, поиск коэффициентов) без участия интегралов.

Согласно лекции, интегрирование рациональных дробей состоит из 5 шагов:
1. **Выделить целую часть**, если дробь неправильная (степень числителя $\ge$ степени знаменателя). Выполняется делением многочленов уголком.
2. У правильной рациональной дроби **разложить знаменатель на простейшие множители** (линейные и квадратичные с отрицательным дискриминантом $D < 0$).
3. Правильную рациональную дробь **разложить на простейшие дроби**. 
   *Количество вводимых букв (неопределенных коэффициентов) строго равно степени знаменателя.*
4. **Найти неопределенные коэффициенты** из составленной системы уравнений (метод приравнивания коэффициентов).
5. **Интегрирование** получившихся простейших дробей.

## 2. Теорема о тождественности многочленов (для шага 4)

Для нахождения неизвестных коэффициентов применяется тождество числителей:
$$
\frac{P(x)}{Q(x)} = \frac{S(x)}{Q(x)} \implies P(x) \equiv S(x)
$$

> 💡 **Смысл / Заметка лектора:** Если два многочлена тождественно равны друг другу, то коэффициенты одного многочлена равны соответствующим коэффициентам другого. Приравнивая коэффициенты при одинаковых степенях $x$ в обеих частях тождества, получим систему линейных уравнений, из которых находим искомые буквы.

**Пример логики:** 
Если $ax^3 + bx^2 + cx + d \equiv x^3 - 3x^2 + 4$, то:
$a = 1$, $b = -3$, $c = 0$, $d = 4$.

## 3. Практика: Метод неопределенных коэффициентов

### Пример 1: Стандартное приравнивание коэффициентов
Разложим дробь:
$$
\frac{2x^2 - 3x - 3}{(x - 1)(x^2 - 2x + 5)} = \frac{A}{x - 1} + \frac{Bx + C}{x^2 - 2x + 5}
$$
Приводим правую часть к общему знаменателю:
$$
\frac{A(x^2 - 2x + 5) + (Bx + C)(x - 1)}{(x - 1)(x^2 - 2x + 5)}
$$
Приравниваем числители и раскрываем скобки:
$$
A(x^2 - 2x + 5) + (Bx + C)(x - 1) = 2x^2 - 3x - 3
$$
$$
Ax^2 - 2Ax + 5A + Bx^2 + Cx - Bx - C = 2x^2 - 3x - 3
$$
Группируем элементы по степеням $x$:
$$
x^2(A + B) + x(-2A - B + C) + x^0(5A - C) = 2x^2 - 3x - 3
$$
Составляем систему уравнений:
$$
\begin{cases} 
A + B = 2 \\ 
-2A - B + C = -3 \\ 
5A - C = -3 
\end{cases}
$$
Решая систему, получаем: $A = -1$, $B = 3$, $C = -2$.
Итоговое разложение:
$$
\frac{2x^2 - 3x - 3}{(x - 1)(x^2 - 2x + 5)} = \frac{-1}{x - 1} + \frac{3x - 2}{x^2 - 2x + 5}
$$

### Пример 2: Использование корней (метод подстановки)
Разложим дробь:
$$
\frac{3x - 4}{x(x - 2)(x + 1)} = \frac{A}{x} + \frac{B}{x - 2} + \frac{C}{x + 1}
$$
Приравниваем числители:
$$
A(x - 2)(x + 1) + Bx(x + 1) + Cx(x - 2) = 3x - 4
$$
Вместо раскрытия скобок подставляем значения $x$, обращающие скобки в ноль:
При $x = 0$: 
$$
-2A = -4 \implies A = 2
$$
При $x = 2$:
$$
6B = 2 \implies B = \frac{1}{3}
$$
При $x = -1$:
$$
3C = -7 \implies C = -\frac{7}{3}
$$
Итоговое разложение:
$$
\frac{2}{x} + \frac{\frac{1}{3}}{x - 2} - \frac{\frac{7}{3}}{x + 1}
$$

## 4. Типы интегралов от простейших дробей (шаг 5)

В теории выделяют несколько базовых типов интегралов, к которым сводится любая рациональная дробь.

**Тип 1. Линейный знаменатель в первой степени:**
$$
\int \frac{A}{x \pm a} \, dx = A \ln |x \pm a| + C
$$

**Тип 2. Линейный знаменатель в степени $n$:**
$$
\int \frac{A}{(x \pm a)^n} \, dx = \frac{A}{1 - n} \cdot \frac{1}{(x \pm a)^{n - 1}} + C
$$

**Тип 3. Квадратичный знаменатель без $x$ в числителе:**
Решается методом **выделения полного квадрата**.
$$
x^2 + px + q = \left(x + \frac{p}{2}\right)^2 + \left(q - \frac{p^2}{4}\right)
$$
Сводится к табличному интегралу арктангенса или «высокого» логарифма:
$$
\int \frac{dx}{x^2 + px + q} = \int \frac{dx}{\left(x + \frac{p}{2}\right)^2 + \left(q - \frac{p^2}{4}\right)}
$$

**Тип 4. Квадратичный знаменатель с $x$ в числителе:**
Применяется метод искусственного формирования производной знаменателя в числителе и метод почленного деления:
$$
\int \frac{Ax + B}{x^2 + px + q} \, dx = \int \frac{\frac{A}{2}(2x + p) + \left(B - \frac{Ap}{2}\right)}{x^2 + px + q} \, dx
$$
Разбиваем на два интеграла:
$$
= \frac{A}{2} \int \frac{2x + p}{x^2 + px + q} \, dx + \left(B - \frac{Ap}{2}\right) \int \frac{dx}{x^2 + px + q}
$$
Первый интеграл всегда дает натуральный логарифм $\frac{A}{2} \ln|x^2 + px + q|$, а второй сводится к Типу 3 (выделение полного квадрата).

## 5. Вычисление интегралов (Разбор примеров)

### Пример на выделение полного квадрата (арктангенс)
$$
\int \frac{dx}{x^2 + 6x + 25} = \int \frac{dx}{(x + 3)^2 + 16}
$$
Замена: $t = x + 3, dt = dx$.
$$
\int \frac{dt}{t^2 + 16} = \frac{1}{4} \text{arctg} \frac{t}{4} + C = \frac{1}{4} \text{arctg} \frac{x + 3}{4} + C
$$

### Пример на интеграл 4-го типа
$$
\int \frac{3x - 1}{x^2 - 4x + 8} \, dx
$$
Формируем в числителе производную знаменателя $(2x - 4)$:
$$
= \int \frac{\frac{3}{2}(2x - 4) + \left(-1 - \frac{3 \cdot (-4)}{2}\right)}{x^2 - 4x + 8} \, dx = \frac{3}{2} \int \frac{2x - 4}{x^2 - 4x + 8} \, dx + 5 \int \frac{dx}{x^2 - 4x + 8}
$$
1) Для первого интеграла замена $t = x^2 - 4x + 8$, $dt = (2x - 4)dx$:
$$
\frac{3}{2} \int \frac{dt}{t} = \frac{3}{2} \ln(x^2 - 4x + 8) + C_1
$$
2) Во втором интеграле выделяем полный квадрат $x^2 - 4x + 8 = (x - 2)^2 + 4$:
$$
5 \int \frac{dx}{(x - 2)^2 + 4} = \frac{5}{2} \text{arctg} \frac{x - 2}{2} + C_2
$$
Общий ответ:
$$
\frac{3}{2} \ln(x^2 - 4x + 8) + \frac{5}{2} \text{arctg} \frac{x - 2}{2} + C
$$

### Пример на использование «Высокого логарифма»
Если при выделении полного квадрата получается разность (минус), применяется формула:
$$
\int \frac{dx}{x^2 - a^2} = \frac{1}{2a} \ln \left| \frac{x - a}{x + a} \right| + C
$$
Допустим, получен интеграл с заменой $t = x + \frac{3}{4}$:
$$
\int \frac{dt}{t^2 - \frac{29}{16}}
$$
Здесь $a^2 = \frac{29}{16}$, следовательно, $a = \frac{\sqrt{29}}{4}$. Подставляем в табличную формулу:
$$
= \frac{1}{2 \cdot \frac{\sqrt{29}}{4}} \ln \left| \frac{t - \frac{\sqrt{29}}{4}}{t + \frac{\sqrt{29}}{4}} \right| + C = \frac{2}{\sqrt{29}} \ln \left| \frac{4t - \sqrt{29}}{4t + \sqrt{29}} \right| + C
$$
Выполняем обратную замену $t = x + \frac{3}{4}$ (и раскрываем скобки внутри логарифма):
$$
= \frac{2}{\sqrt{29}} \ln \left| \frac{4\left(x + \frac{3}{4}\right) - \sqrt{29}}{4\left(x + \frac{3}{4}\right) + \sqrt{29}} \right| + C = \frac{2}{\sqrt{29}} \ln \left| \frac{4x + 3 - \sqrt{29}}{4x + 3 + \sqrt{29}} \right| + C
$$
