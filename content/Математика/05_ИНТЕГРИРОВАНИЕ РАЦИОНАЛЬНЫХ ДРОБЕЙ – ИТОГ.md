**Тема:** Полный цикл интегрирования рациональных дробей (от 4-й до 6-й степени знаменателя).
**Цель занятия:** Объединить все пройденные методы и отработать 5 пунктов плана на полных примерах.

---

## 📌 Универсальный алгоритм из 5 шагов (Теоретическая база)

1. **Определение типа дроби (Правильная/Неправильная):**
   * Если степень числителя $\ge$ степени знаменателя — дробь **неправильная**. Выделяем целую часть делением «уголком». 
   * *Важный совет лектора:* Если в остатке от деления появляется общий множитель (например, все числа кратны 4), **не выносите его за знак интеграла**. Иначе коэффициенты $A, B, C\dots$ получатся дробными. Оставляйте числитель как есть.
   * Дальнейшая работа (шаги 2–5) идет **только с правильной дробью** (остатком). Целая часть просто интегрируется отдельно.

2. **Разложение знаменателя на множители:**
   * Раскладываем знаменатель правильной дроби на простейшие множители: линейные (например, $x$, $x-1$) и квадратичные, не имеющие корней ($D < 0$, например, $x^2+2x+2$). *Для этого нужно помнить школьные формулы сокращенного умножения.*

3. **Разложение на простейшие дроби (введение неопределенных коэффициентов):**
   * Расписываем правильную дробь как сумму простейших. **Количество вводимых букв строго равно степени знаменателя.**
   * Повторяющиеся множители (например, $x^2$) расписываем по степеням: $\frac{A}{x} + \frac{B}{x^2}$.
   * Для неразложимых квадратных знаменателей в числителе пишем линейную функцию: $\frac{Cx+D}{x^2+2x+2}$.

4. **Нахождение коэффициентов ($A, B, C, D\dots$):**
   * Приводим дроби к **наименьшему** общему знаменателю (подбирая недостающие множители для каждой дроби).
   * Приравниваем числители получившейся дроби и исходной правильной дроби.
   * Раскрываем все скобки, группируем слагаемые при одинаковых степенях $x$ ($x^3, x^2, x^1, x^0$).
   * Составляем систему уравнений: приравниваем коэффициенты при соответствующих степенях слева и справа.
   * *Альтернатива:* **Метод частных значений** — подстановка корней знаменателя вместо $x$ для быстрого нахождения части коэффициентов.

5. **Интегрирование простейших дробей:**
   * Дроби с линейными знаменателями дают логарифмы.
   * Дроби с квадратичными знаменателями разбиваются на два интеграла: первый решается заменой (подгонка числителя под производную знаменателя), второй — выделением полного квадрата.

## 📝 Разбор примеров

### Пример №1. Знаменатель 4-й степени
**Интеграл:** 
$$
\int \frac{x^5 + 2x^3 + 4x + 4}{x^4 + 2x^3 + 2x^2} dx
$$

**Шаг 1. Выделение целой части**
Степень числителя (5) $>$ степени знаменателя (4). Делим уголком:

$$
\begin{array}{rl}
\begin{array}{rl}
  - & x^5 + 2x^3 + 4x + 4 \\
    & \underline{x^5 + 2x^4 + 2x^3} \\
  - & \phantom{x^5} -2x^4 + 4x + 4 \\
    & \phantom{x^5} \underline{-2x^4 - 4x^3 - 4x^2} \\
    & \phantom{x^5 - 2x^4} 4x^3 + 4x^2 + 4x + 4
\end{array} &
\begin{array}{|l}
  x^4 + 2x^3 + 2x^2 \\
  \hline
  x - 2
  \\ \,
  \\ \,
  \\ \,
\end{array}
\end{array}
$$

Интеграл от целой части: $\int (x - 2) dx = \frac{x^2}{2} - 2x$.

**Шаг 2. Разложение знаменателя**
$x^4 + 2x^3 + 2x^2 = x^2(x^2 + 2x + 2)$
*(У $x^2 + 2x + 2$ дискриминант $D<0$, он простейший и дальше не раскладывается).*

**Шаг 3 и 4. Разложение на простейшие дроби и поиск коэффициентов**
Вводим 4 буквы:

$$
\frac{4x^3 + 4x^2 + 4x + 4}{x^2(x^2 + 2x + 2)} = \frac{A}{x} + \frac{B}{x^2} + \frac{Cx + D}{x^2 + 2x + 2}
$$

Приводим правую часть к общему знаменателю $x^2(x^2 + 2x + 2)$:

$$
= \frac{Ax(x^2 + 2x + 2) + B(x^2 + 2x + 2) + (Cx + D)x^2}{x^2(x^2 + 2x + 2)}
$$

Приравниваем числители:

$$
Ax(x^2 + 2x + 2) + B(x^2 + 2x + 2) + (Cx + D)x^2 = 4x^3 + 4x^2 + 4x + 4
$$

Раскрываем скобки:

$$
Ax^3 + 2Ax^2 + 2Ax + Bx^2 + 2Bx + 2B + Cx^3 + Dx^2 = \dots
$$

Группируем слагаемые:

$$
(A + C)x^3 + (2A + B + D)x^2 + (2A + 2B)x + 2B = 4x^3 + 4x^2 + 4x + 4
$$

Составляем систему уравнений:

$$
\begin{cases}
x^3: A + C = 4 \\
x^2: 2A + B + D = 4 \\
x^1: 2A + 2B = 4 \\
x^0: 2B = 4 
\end{cases}
$$

*Быстрый способ:* Подставив $x=0$, сразу получим $2B = 4 \Rightarrow B=2$.
Решаем систему: $B=2 \Rightarrow A=0 \Rightarrow C=4 \Rightarrow D=2$.
*(Дробь с коэффициентом $A$ исчезает).*

**Шаг 5. Интегрирование**
Подставляем найденные числа:

$$
\int \left( \frac{2}{x^2} + \frac{4x + 2}{x^2 + 2x + 2} \right) dx
$$

1) $\int \frac{2}{x^2} dx = -\frac{2}{x}$
2) $\int \frac{4x + 2}{x^2 + 2x + 2} dx$
   Выделяем в числителе производную знаменателя ($(x^2+2x+2)' = 2x+2$): $4x+2 = 2(2x+2) - 2$.
   Разбиваем на два интеграла:
   
$$
2 \underbrace{\int \frac{(2x + 2)dx}{x^2 + 2x + 2}}_{\text{①}} - 2 \underbrace{\int \frac{dx}{x^2 + 2x + 2}}_{\text{②}}
$$

   **Интеграл ① (Замена):**
   
$$
\left( \begin{array}{l} t = x^2 + 2x + 2 \\ dt = (2x + 2)dx \end{array} \right) \Rightarrow \int \frac{dt}{t} = \ln|t| = \ln(x^2 + 2x + 2)
$$

   **Интеграл ② (Полный квадрат):** $x^2 + 2x + 2 = (x + 1)^2 + 1$.
   
$$
\left( \begin{array}{l} t = x + 1 \\ dt = dx \end{array} \right) \Rightarrow \int \frac{dt}{t^2 + 1} = \operatorname{arctg} t = \operatorname{arctg}(x + 1)
$$

**Итоговый ответ №1:**

$$
\frac{x^2}{2} - 2x - \frac{2}{x} + 2\ln(x^2 + 2x + 2) - 2 \operatorname{arctg}(x + 1) + C
$$

### Пример №2. Знаменатель 5-й степени
**Интеграл:** 
$$
\int \frac{dx}{x^5 - x^2}
$$

**Шаги 1 и 2.** Дробь правильная. Раскладываем знаменатель (выносим $x^2$, затем формула разности кубов):

$$
x^5 - x^2 = x^2(x^3 - 1) = x^2(x - 1)(x^2 + x + 1)
$$

**Шаги 3 и 4. Введение и поиск коэффициентов**
Вводим 5 букв:

$$
\frac{1}{x^2(x - 1)(x^2 + x + 1)} = \frac{A}{x} + \frac{B}{x^2} + \frac{C}{x - 1} + \frac{Dx + E}{x^2 + x + 1}
$$

Приводим к общему знаменателю и приравниваем числители:

$$
Ax(x - 1)(x^2 + x + 1) + B(x - 1)(x^2 + x + 1) + Cx^2(x^2 + x + 1) + (Dx + E)x^2(x - 1) = 1
$$

Раскрываем скобки:

$$
Ax^4 - Ax + Bx^3 - B + Cx^4 + Cx^3 + Cx^2 + Dx^4 - Dx^3 + Ex^3 - Ex^2 = 1
$$

Составляем систему уравнений:

$$
\begin{cases}
x^4: A + C + D = 0 \\
x^3: B + C - D + E = 0 \\
x^2: C - E = 0 \\
x^1: -A = 0 \Rightarrow A = 0 \\
x^0: -B = 1 \Rightarrow B = -1
\end{cases}
$$

Решая систему, получаем: 

$$
\begin{cases}
A = 0 \\ B = -1 \\ C = 1/3 \\ D = -1/3 \\ E = 1/3
\end{cases}
$$

**Шаг 5. Интегрирование**
Подставляем коэффициенты:

$$
\int \left( \frac{-1}{x^2} + \frac{1/3}{x - 1} + \frac{-1/3 x + 1/3}{x^2 + x + 1} \right) dx
$$

* $\int -\frac{1}{x^2} dx = \frac{1}{x}$
* $\int \frac{1/3}{x - 1} dx = \frac{1}{3}\ln|x - 1|$
* Последняя дробь (выносим $-1/3$): $-\frac{1}{3} \int \frac{x - 1}{x^2 + x + 1} dx$.
  P.s.: Делаем по нашему алгоритму, хоть и дальше верно сказано – Производная знаменателя: $2x + 1$. Подгоняем числитель: $x - 1 = \frac{1}{2}(2x + 1) - \frac{3}{2}$.
  Разбиваем на два интеграла:
  
$$
\frac{1}{2} \underbrace{\int \frac{2x + 1}{x^2 + x + 1} dx}_{\text{①}} - \frac{3}{2} \underbrace{\int \frac{dx}{x^2 + x + 1}}_{\text{②}}
$$

  **① (Замена):**
  
$$
\left( \begin{array}{l} t = x^2 + x + 1 \\ dt = (2x + 1)dx \end{array} \right) \Rightarrow \int \frac{dt}{t} = \ln|t| = \ln(x^2 + x + 1)
$$

  **② (Полный квадрат):** $x^2 + x + 1 = (x + 1/2)^2 + 3/4$.
  
$$
\left( \begin{array}{l} t = x + 1/2 \\ dt = dx \end{array} \right) \Rightarrow \int \frac{dt}{t^2 + 3/4} = \frac{2}{\sqrt{3}} \operatorname{arctg} \frac{2t}{\sqrt{3}} = \frac{2}{\sqrt{3}} \operatorname{arctg} \frac{2x + 1}{\sqrt{3}}
$$

**Итоговый ответ №2:**
Мы сократили $3/2$ и $2/\sqrt{3}$ до $\sqrt{3}$.

$$
\frac{1}{x} + \frac{1}{3}\ln|x - 1| - \frac{1}{3} \left( \frac{1}{2}\ln(x^2 + x + 1) - \sqrt{3} \operatorname{arctg} \frac{2x + 1}{\sqrt{3}} \right) + C
$$

### Пример №3. Знаменатель 6-й степени (Демонстрация метода частных значений)
**Интеграл:** 
$$
\int \frac{(x^2 + 2)dx}{x(x + 1)^2(x - 1)^3}
$$

Знаменатель 6-й степени, вводим 6 букв:

$$
\frac{A}{x} + \frac{B}{x + 1} + \frac{C}{(x + 1)^2} + \frac{D}{x - 1} + \frac{E}{(x - 1)^2} + \frac{F}{(x - 1)^3}
$$

Приводим к общему знаменателю и приравниваем числители:

$$
A(x + 1)^2(x - 1)^3 + Bx(x + 1)(x - 1)^3 + Cx(x - 1)^3 + Dx(x + 1)^2(x - 1)^2 + Ex(x + 1)^2(x - 1) + Fx(x + 1)^2 = x^2 + 2
$$

Раскрывать скобки и составлять систему 6х6 нерационально. Используем **метод частных значений**: подставляем вместо $x$ корни знаменателя, чтобы обнулить слагаемые.
* Подставим $x=0$: $-A = 2 \Rightarrow \mathbf{A = -2}$
* Подставим $x=-1$: $-8C = 3 \Rightarrow \mathbf{C = -3/8}$
* Подставим $x=1$: $4F = 3 \Rightarrow \mathbf{F = 3/4}$

Корни закончились, берем любые другие простые числа (например, $x=2$):
Подставим 
$x=2$: $9A + 6B + 2C + 18D + 18E + 18F = 6$.
Так как $A, C, F$ уже известны, мы подставляем их в уравнение. Сделав то же самое для $x=-2$ и $x=3$, получим систему всего из 3 уравнений с 3 неизвестными ($B, D, E$), что решается гораздо быстрее.
